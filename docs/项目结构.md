# 项目结构

```text
finance-os/
├── README.md
├── backend/                  Java 21 / Spring Boot 3
│   ├── src/main/java/        业务模块、Controller、Service、Mapper
│   ├── src/main/resources/db/migration/  Flyway V1–V13
│   ├── src/test/             单元与 PostgreSQL Testcontainers 测试
│   └── Dockerfile、pom.xml
├── frontend/                 React / TypeScript / Vite
│   ├── src/、tests/、nginx/
│   └── Dockerfile
├── docker/                   正式使用的 Compose 入口与 .env.example
├── database/                 数据库相关材料
├── scripts/                  本地开发脚本
└── docs/
    ├── 03-Architecture/      冻结 Architecture、当前 Database/API
    ├── ADR/                  架构决策记录
    ├── design/、review/      历史设计与验收记录
    ├── logs/、meeting/、decisions/
    └── 当前产品、规则、质量与指南文档
```

`docker/` 已正式使用，不是预留目录。当前 schema 来自 versioned migration；Architecture 是冻结 v1.0 基线，当前能力以活文档、ADR 和 Closing Review 的对应职责为准。
