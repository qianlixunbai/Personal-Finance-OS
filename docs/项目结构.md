# 项目结构

本文给出当前仓库的可导航结构，粒度高于根 README，但不枚举所有类和测试文件。

## 1. 仓库总览

```text
finance-os/
├── README.md
├── backend/                  Java 21 / Spring Boot 3 模块化单体
├── frontend/                 React / TypeScript / Vite
├── docker/                   Docker Compose 单机部署入口
├── database/                 数据库相关材料
├── scripts/                  本地开发脚本
└── docs/                     产品、架构、规则、设计与验收文档
```

`docker/` 已正式使用，不是预留目录。当前 schema 来自 versioned Flyway migration；根 README 只展示缩略结构，本文负责开发导航。

常规模块使用 Controller → DTO → Service → Mapper/Entity 分层。投资模块按领域职责拆分，不把 calculator/replay、Instrument、opening migration 和公开 command 混成单一 Service。

## 3. 后端资源与 Migration

```text
backend/src/main/resources/
├── application.yml
├── application-prod.yml
└── db/migration/
    ├── V1__baseline.sql
    ├── V2__market_quotes.sql
    ├── V3__exchange_rates.sql
    ├── V4__investment_ledger_foundation.sql
    ├── V5__harden_investment_ledger_constraints.sql
    ├── V6__align_asset_projection_precision.sql
    ├── V7__create_investment_instruments.sql
    ├── V8__bind_asset_positions_to_instruments.sql
    ├── V9__harden_opening_position_migration.sql
    ├── V10__harden_investment_write_receipts.sql
    ├── V11__harden_dividend_write_receipts.sql
    ├── V12__add_append_only_investment_reversals.sql
    └── V13__add_investment_transaction_replacements.sql
```

V1–V13 是 schema 唯一演进链。新变更新增后续 migration，不修改历史文件，不恢复旧 `schema.sql` 初始化路径。

```text
frontend/
├── src/
│   ├── api/                  Axios API 封装
│   ├── components/           通用布局、反馈、分页与可视组件
│   │   ├── charts/           ECharts 图表与数据适配
│   │   └── dashboard/        Dashboard 专用面板
│   ├── hooks/                前端 hooks
│   ├── pages/                Login、Register、Dashboard、Accounts、Assets、Transactions

│   ├── utils/                格式化与错误/估值辅助
│   ├── App.tsx               路由
│   └── main.tsx              应用入口
├── tests/                    Node test：跳转、分页、行情、估值、图表数据
```

当前前端覆盖基础财务和参考估值页面；后端投资读取 API 已实现，但没有投资账本写入、读取或纠正 UI。`sites-demo` 是独立静态只读分支，不在本结构中作为当前开发目录展开。

## 6. Docker 与脚本

```text
docker/
├── compose.yml               postgres + backend + frontend
└── .env.example              本地 Compose 环境模板

scripts/
└── dev-start-backend.ps1     本地后端启动辅助
```

Compose 使用 PostgreSQL 17、后端 readiness healthcheck 与前端 nginx healthcheck。密码和密钥只写入未跟踪的本地 `.env`，不得提交。
