## 根目录

- `README.md`：GitHub 作品集首页和项目入口。
- `backend/`：Java 21 + Spring Boot 3 后端代码。
- `frontend/`：React + TypeScript + Vite 前端代码。
- `database/`：数据库相关目录。
- `scripts/`：本地开发脚本。
- `docker/`：Docker 相关预留目录。当前项目文档不提供 Docker 启动方案，Docker 部署属于后续规划。

## docs 根文件

- `docs/README.md`：文档中心导航页。
- `docs/Project Vision.md`：项目愿景。
- `docs/Roadmap.md`：阶段性路线图。
- `docs/SRS.md`：软件需求规格说明。
- `docs/SRS详解.md`：需求说明补充材料。
- `docs/Business Rules.md`：业务规则。
- `docs/Financial Rules.md`：金融领域规则。
- `docs/Development-Guide.md`：开发流程和本地开发约定。
- `docs/AI-Rules.md`：AI 辅助开发边界。
- `docs/Prompt Guide.md`：提示词协作指南。
- `docs/Code Review Checklist.md`：代码审查检查清单。
- `docs/Definition of Done.md`：任务完成标准。
- `docs/项目结构.md`：当前文件。
