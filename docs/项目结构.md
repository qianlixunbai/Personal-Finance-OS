# 项目结构

以下是当前仓库的主要结构；构建产物、依赖目录和每个测试文件不在此逐项展开。

```text
finance-os/
├── README.md
├── backend/                         Java 21 / Spring Boot 3 application
│   ├── src/main/java/                modules, Controllers, services, mappers
│   ├── src/main/resources/
│   │   └── db/migration/             Flyway V1–V13
│   ├── src/test/                     unit and PostgreSQL Testcontainers tests
│   ├── Dockerfile
│   └── pom.xml
├── frontend/                         React / TypeScript / Vite application
│   ├── src/
│   ├── tests/
│   ├── nginx/
│   └── Dockerfile
├── docker/                           active Compose deployment entry point
│   ├── compose.yml
│   └── .env.example
├── scripts/                          local development helpers
├── database/                         database-related project materials
└── docs/
    ├── 03-Architecture/              frozen Architecture plus active Database/API
    ├── ADR/                          immutable architecture decision records
    ├── design/                       historical design records
    ├── review/                       historical Closing Reviews and review index
    ├── logs/, meeting/, decisions/   historical working records
    ├── README.md                     documentation navigation
    └── *.md                          active product, rule, quality, and guide docs
```

`docker/` is in active use, not a placeholder. The active schema is defined by the versioned migrations, not by a standalone schema file. [Architecture](03-Architecture/Architecture.md) is the frozen v1.0 baseline; current implementation context comes from the active Database/API/rules documents plus ADR and Closing Review records.
