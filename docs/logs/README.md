# Development Logs

This directory records key project events, environment issues, fixes, and verification results.

Recording rules:

- Only keep entries that help future maintenance.
- Every log should include the goal, the issue, the process, validation, and the conclusion.
- Important fixes should describe impact and residual risk.
- Logs are for knowledge capture, not a replacement for code, tests, or formal ADRs.
