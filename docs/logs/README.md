# Development Logs

本目录用于记录项目开发过程中的关键事件、环境问题、修复过程与验证结果。

记录原则：

- 只记录对项目后续维护有价值的内容。
- 每篇日志必须包含目标、问题、处理过程、验证结果和结论。
- 重要修复需要说明影响范围与残留风险。
- 日志用于沉淀经验，不替代代码、测试或正式 ADR。
