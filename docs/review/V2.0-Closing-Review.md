# v2.0 Market Data Foundation Closing Review

本文档记录 Personal Finance OS `v2.0 Market Data Foundation` 的正式关闭结论，以及关闭后的展示层小型收口。v2.0 目标是增加受边界约束的参考行情能力，不改变既有 CNY 资产估值、Dashboard 或投资交易模型。

## 1. 版本目标

- 为 US `STOCK` / `ETF` 提供独立、可追溯的最新参考行情快照；
- 保持金融计算以后端 CNY 资产数据为准；
- 使用缓存、single-flight、额度保护和失败降级控制外部 Provider 风险；
- 以手动单 Asset 刷新展示行情，不引入自动刷新或新的市场能力。

## 2. 完成范围

- 新增独立 `market_quotes` 最新快照和 Twelve Data adapter；
- 仅支持 US `STOCK` / `ETF`，刷新前验证资产归属、市场、类型和 symbol；
- 支持 `CACHE_HIT`、`UPDATED`、`STALE_FALLBACK` 三种刷新结果；
- Asset list、page、detail 只读附加缓存行情；
- Assets 页面支持单行手动刷新和新鲜度展示；
- Closing Fix 补齐非 US 资产拒绝刷新、GET 过滤、额度与持久化失败回归；
- 展示收口将前端刷新入口与同一 US 边界对齐。

## 3. Market Data 架构与边界

- `market_quotes` 保存 `(market, symbol)` 的独立最新快照；
- Twelve Data adapter 仅负责请求、响应校验和标准化，不直接修改 Asset；
- 功能默认关闭，启用需要 `MARKET_DATA_ENABLED=true` 与 `MARKET_DATA_API_KEY`；
- 当前仅接受规范化后为 `US` 的 `STOCK` / `ETF` 资产；
- 合法 symbol 是行情能力的输入边界，普通 GET 对无效 symbol 返回无行情状态。

## 4. 缓存与刷新流程

- TTL 默认 15 分钟；
- 新鲜缓存直接返回 `CACHE_HIT`，不请求 Provider；
- 过期或缺失快照才允许进入刷新流程；
- 手动刷新只针对单个本人 Asset；
- list/page 批量读取合格 symbol 的 US 缓存，detail 读取一个合格缓存，避免 N+1；
- 页面加载只读取 Asset API 返回的缓存快照，不调用刷新 API。

## 5. single-flight 与额度保护

- 同一 `(US, symbol)` 的并发刷新由进程内 single-flight 合并；
- Provider 调用受每用户和全局每分钟额度保护；
- 缓存命中不消耗额度；
- single-flight 与额度保护均为单进程机制，不是分布式协调方案；
- 失败路径会清理 single-flight key，后续请求可以再次尝试刷新。

## 6. stale fallback

- Provider、用户额度或全局额度失败时，如存在旧快照，返回 `STALE_FALLBACK`；
- fallback 保留最近一次成功快照的 price、quoteTime 和 fetchedAt；
- 无缓存时按错误语义返回 404、429、502 或 503；
- 前端对 `STALE_FALLBACK` 使用固定中文说明，不展示 Provider 原始错误。

## 7. Security 与用户隔离

- 刷新接口从 Spring Security `Authentication principal` 获取 userId；
- Service 先验证 Asset 存在且属于当前用户；
- 刷新他人 Asset 返回 404；
- 非 US、空白或缺失 market 在访问缓存、额度、Provider 和持久化之前返回 400；
- 开启行情所需 API key 仅由环境变量或部署 Secret Store 配置，不写入仓库。

## 8. 金融边界

- 外部行情仅写入 `market_quotes`；
- 不写入 `Asset.currentPrice` 或 `Asset.marketValue`；
- 不参与 Dashboard 或 CNY 总资产估值；
- 不引入汇率、多币种估值、完整投资交易、实现盈亏或自动重估；
- 参考行情不能替代用户确认的业务数据。

## 9. 前端展示

- 人工估值价格明确标记为 CNY；
- 参考行情使用后端返回的 currency；
- 单行刷新仅替换该行 `marketQuote`，不触碰人工估值字段；
- 仅当 type 为 `STOCK` / `ETF`、market 规范化后为 `US` 且 symbol 非空白时显示行情入口；
- 非 US 资产不显示可操作刷新入口；
- 行情功能关闭时，页面仍可读取已有快照或呈现无行情状态。

## 12. 独立复审结果

关闭复验核对了提交范围、US 市场边界、非 US 拒绝与 GET 过滤、用户和全局额度 fallback/429、持久化失败重试、金融隔离、前端 fallback、文档与 Secret。结论：P0 0、P1 0，允许 v2.0 正式关闭。

## 13. 已知限制

- 主 bundle 约 872 kB，仍有 Vite 500 kB warning；
- single-flight 和额度保护仅在单进程内有效；
- 仅支持 US 市场；
- 不支持历史行情；
- 不支持汇率和多币种估值；
- 不支持自动刷新；
- 不支持完整投资交易模型。

## 14. 明确未纳入 v2.0 的内容

- 其他市场、历史行情、OHLC、盘前盘后和涨跌幅；
- 汇率、多币种资产总额与市场估值；
- 自动或定时刷新；
- 买卖、股息、拆股、手续费、税费和实现盈亏；
- 分布式额度控制、Redis、MQ 或微服务拆分。

## 15. 后续建议

- 在后续版本按业务规则设计多币种估值和汇率来源；
- 再评估历史行情、图表和定时刷新；
- 如需横向扩展，再将 single-flight 与额度保护替换为跨进程协调；
- 在展示层优化中按需拆分前端 bundle，而不作为 v2.0 阻塞项。

## 16. 最终结论

v2.0 Market Data Foundation 已在不改变 CNY 资产估值、Dashboard 和既有金融边界的前提下完成。关闭复验无 P0/P1，后续展示层收口已对齐前端刷新入口与 US 市场边界。
