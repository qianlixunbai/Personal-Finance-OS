## Empty Position decision

No transaction-driven Position is created by this phase. Existing ledger semantics define `Asset` as a projection of an investment fact; a zero-quantity, CLOSED projection without a fact would violate that boundary. The internal binding service only validates an Account + Instrument pair for the future atomic investment command.

## Verification

- PostgreSQL 17 Testcontainers were run for migration, V6 upgrade/fail-fast, Mapper constraints, and concurrent Instrument creation.
- Concurrent Instrument creation yields one success and one 409; the unique key leaves one row.
- `23505` is translated to 409 only for the named Instrument unique constraint. Other database integrity failures are rethrown to the existing generic handler.
