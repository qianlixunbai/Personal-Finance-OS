# v2.1 Market Valuation Closing Review

**Review 状态：** GO

**阶段范围：** v2.1 Market Valuation，包含 FX Foundation、FX Refresh Workflow、Reference Valuation Backend 和 Assets UI 四个阶段。

## 1. 完成情况

- Phase 1 FX Foundation：Exchange Rate 表和持久化、BigDecimal 汇率精度、Provider abstraction、PostgreSQL Testcontainers 与 ADR-006 已完成。
- Phase 2 FX Refresh Workflow：TTL、`CACHE_HIT`、`UPDATED`、`STALE_FALLBACK`、single-flight、用户级与全局额度、默认关闭和安全错误处理已完成。
- Phase 3 Reference Valuation Backend：Quote、FX 与 CNY 参考估值组合、只读 GET、显式刷新、freshness 状态、结构化 warning、list/page 批量查询已完成；Phase 3 P1 修复已完成。
- Phase 4 Assets UI：人工估值与市场参考估值分区、原生和 CNY 参考值展示、单 Asset 刷新、安全 warning 映射、失败保留旧数据已完成。
- Phase 4 已通过 Sol 只读验收，无 P0/P1。

## 2. 验证结果

- 前端测试、lint、build：通过。
- 后端测试：通过。
- GitHub Actions Frontend、Backend、Deployment artifacts：全部成功。
- 本次文档收口未重新运行 Maven 或前端测试；以上结果沿用 v2.1 完成验收记录。

## 3. 关键业务不变量

- Account 和普通 Transaction 仍只支持 CNY。
- Asset 人工 `currentPrice`、`marketValue` 仍是账务数据，不被市场参考估值覆盖。
- Market Quote 和 FX 是外部参考输入；Reference Valuation 是只读、非持久化派生结果。
- 普通 GET 不调用 Provider，只有显式 POST 才可能刷新 Quote 或 FX。
- Provider 失败不会修改账务真值；Dashboard 未接入市场参考估值；真实 FX Provider 默认关闭。
- v2.1 不包含历史行情、定时刷新、自动批量刷新或完整投资交易模型。
