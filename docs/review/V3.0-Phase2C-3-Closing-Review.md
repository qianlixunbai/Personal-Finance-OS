## 2. 交付范围

前端新增 `/investments` 工作区并接入主路由与导航，直接消费以下冻结 API：

- `GET /api/v1/investment/portfolio`
- `GET /api/v1/investment/positions`
- `GET /api/v1/investment/positions/{positionId}`
- `GET /api/v1/investment/transactions`
- `GET /api/v1/investment/transactions/{logicalTransactionId}`
- `GET /api/v1/investment/transactions/{logicalTransactionId}/audit`

页面包含 Portfolio 摘要、Position 列表/详情、logical transaction 列表/详情与 audit timeline。Position 与 transaction 各自维护独立 opaque cursor 历史；筛选变化会重置对应分页，Position 可以跳转到已按持仓筛选的交易视图。

## 3. 契约与金融语义

- Portfolio、成本、累计已实现盈亏、参考估值与警告全部以后端响应为准，前端不重新聚合核心金融数据。
- 所有金额、数量和价格保持 `string | null`，未使用 `Number`、`parseFloat`、`toFixed` 或浮点运算重算投资值。
- `referenceValuation` 的 `AVAILABLE` / `UNAVAILABLE`、`null` 值和 warnings 均有明确展示。
- Position 详情分开呈现手工账面值与缓存参考值，未把缓存参考行情当作账务真值。
- logical transaction 支持 `UNCHANGED`、`REVERSED`、`REPLACED`；详情区分 original / effective business values。
- posting receipt、correction final receipt 与 current position 作为三个不同语义层展示；`UNCHANGED` 不伪造 correction receipt，允许 posting receipt 为空。
- audit timeline 覆盖 original posting、standalone reversal、replacement command、grouped reversal 和 replacement fact；`NOT_APPLICABLE` 明确显示为“不适用”。
- 已知枚举使用中文标签，未知运行时值提供安全回退，不会渲染空标签或使页面崩溃。

## 4. 并发请求、错误与认证

- Position detail、transaction detail 与 audit 各有独立 latest-request gate；切换目标会清空旧内容并使迟到响应失效。
- 浏览器竞态测试分别延迟 Position、transaction 与 audit 请求，最终页面始终保留用户最后选择的记录和时间线。
- `400` 显示筛选条件错误，`404` 显示资源不存在或不可访问，`500` 使用脱敏通用提示；错误后旧详情和旧 audit 不残留。
- `401` 由现有 Axios 认证链清除 token 并返回登录页，未出现重定向循环。

## 5. 真实后端与数据验收

使用 Java 21、本地 Spring Boot、独立临时 `postgres:17-alpine` 容器和真实 Vite 页面完成端到端验收。测试库只通过公开注册、账户与 investment command API 建立数据，未直接写数据库；临时容器在验收后已删除，未影响本机既有 PostgreSQL。

真实数据包含：

- 22 个 Position（21 OPEN、1 CLOSED）和 23 个 logical transaction；
- 正常 BUY / SELL、负 realized PnL、standalone reversal 与 replacement；
- 超过默认 page size 的 Position 与 transaction，验证真实 next / previous cursor；
- UNCHANGED、REVERSED、REPLACED 详情和各自 audit；
- grouped reversal 的 `NOT_APPLICABLE`、replacement command 中可空 `factType`；
- posting、correction final、current position 三层可实际不同的回执/快照；
- 真实 `400`、`401`、`404`，以及浏览器拦截的脱敏 `500` 展示。
