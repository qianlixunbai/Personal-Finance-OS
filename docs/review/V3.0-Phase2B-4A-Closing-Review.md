## Write-path guarantees reviewed

- ADR-011 remains the governing design: Account -> Instrument -> Asset lock order, CNY-only accounting, negative balances allowed, immutable receipts, server-owned posting time, and transaction-wide rollback.
- `AccountBalanceService` remains the production writer for Account balances.
- BUY/SELL receipt snapshots are immutable and idempotent replays restore the original result rather than current projection values.
- All write-path lock queries are user-scoped; production consistency checking is invoked after projection update.
- No DIVIDEND, correction/reversal/replacement public write API, Portfolio work, or frontend changes were introduced.
