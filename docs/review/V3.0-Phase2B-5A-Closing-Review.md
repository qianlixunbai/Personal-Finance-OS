# V3.0 Phase 2B-5A Closing Review

## Scope and decision record

This review covers append-only reversal of `BUY`, `SELL`, and `DIVIDEND` only. It does not add replacement, any OPENING_POSITION or legacy-opening correction, partial reversal, reversal chains, Portfolio, multi-currency, or frontend work. ADR-013 is accepted: originals and receipts remain immutable `POSTED` facts; a new `POSTED REVERSAL` fact excludes its `original_transaction_id` target from the replay effective set. ADR-007 remains historical; its future mutable `REVERSED` semantics are superseded, not rewritten.

## Implemented evidence

- V12 fails fast for historical `REVERSED`, `reversed_at`, `reversal_reason`, or `replaces_transaction_id` data, adds the append-only fields and named partial unique reversal index, preserves the frozen `NUMERIC(28,2)` money-fact precision, and installs immutable-fact and reversal-audit PostgreSQL triggers.
- The command locks `Original InvestmentTransaction -> Account -> Instrument -> Asset`, uses candidate replay before insert, persists one `REVERSAL`, applies the cash delta once, performs second replay, updates projection metadata exactly once, and verifies persisted Account/Asset/Reversal consistency without overwriting current price or market value.
- API coverage includes strict reason/key parsing, unknown JSON rejection, 404 ownership isolation, 409 unsupported/candidate-conflict semantics, same-key replay, different-key/original conflict, BUY/partial SELL/full SELL/DIVIDEND reversals, and inactive Account/Instrument operation.
- PostgreSQL 17.10 Testcontainers coverage includes V11-to-V12 and V1-to-V12 migration, fail-fast legacy data, field/trigger/immutability constraints, replay, concurrency, four lock timeout/release paths, and a real `40P01` deadlock victim. Reversal specialist tests use `CyclicBarrier`, `pg_stat_activity`, and bounded `Future.get`; they add no `Thread.sleep` ordering.
- A real PostgreSQL `BEFORE INSERT` reversal-trigger failure returns a sanitized 500 and rechecks, outside the transaction, that no reversal, balance mutation, or projection change remains.
