# Review Reports

このディレクトリには、プロジェクトの重要な Review 結果を保存します。対象には、アーキテクチャ Review、コード Review、データベース Review、API Review、リリース前 Review が含まれます。

記録ルール:

- Review レポートでは、問題、リスク、結論を優先して記載する。
- 凍結済みの設計文書は Review レポート内で直接変更しない。
- Review の結論では、次の工程をブロックするかどうかを明記する。
- 修正過程は `docs/logs/` に記録し、重大な決定は `docs/ADR/` に記録する。
