# 路线图

## 当前阶段

`v3.0 Phase 2B Investment Write Foundation` 已关闭并获得 GO。它完成了 Instrument 与绑定、opening migration、BUY/SELL/DIVIDEND、重放投影、余额联动、追加式反转与替换纠正、幂等和并发安全。历史验收证据见 [Phase 2B Closing Review](review/V3.0-Phase2B-Closing-Review.md)。

## 下一阶段

`Phase 2C-1 Investment Read Model Contract` 尚未开始。其目标是冻结 Portfolio 和 InvestmentTransaction 读取语义；不在本阶段提前实现读取 API、投资前端、行情扩展、快照、多币种或批量迁移。

## 已关闭阶段

v1.x Foundation / Engineering、v2.x Market Data / Valuation、v3.0 Phase 1、Phase 2A 与 Phase 2B 的历史范围、测试数字和 GO/NO-GO 结论均保留在对应 Closing Review，不作为当前全局指标。

## 后续方向

投资读取模型与 UI、`TRANSFER` / `REFUND`、历史持仓和收益、FIFO/lot、多币种账务、公司行动、账单导入、自动同步、AI Agent 和原生移动端均需单独定义范围后再实施。
