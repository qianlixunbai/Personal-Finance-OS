# Archive

本目录保存 Historical Evidence，不是当前产品状态或当前实现的替代来源。

| 目录 | 内容 | 保护规则 |
| --- | --- | --- |
| [design](design/) | 某阶段实施前冻结或审查过的方案 | 保留当时范围、假设与设计结论 |
| [review](review/README.md) | Closing Review、专项 Review 与验收证据 | 保留 HEAD、SHA、测试数字、P0/P1/P2/P3、GO/NO-GO |
| [logs](logs/README.md) | 早期环境、排障与修复记录 | 保留当时问题、处理过程与结论 |

归档文件可以修复因移动造成的相对链接，但不得因为当前实现已经变化而改写历史事实。

当前状态见 [STATUS](../STATUS.md)，当前架构见 [Current Architecture](../architecture/current-architecture.md)，长期决策见 [ADR](../ADR/README.md)。
