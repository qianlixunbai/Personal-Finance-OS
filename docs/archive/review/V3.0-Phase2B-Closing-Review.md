# v3.0 Phase 2B 聚合 Closing Review

## 范围与关闭决策

Phase 2B 关闭继 v3.0 账本基础与 Phase 2A 账户余额并发工作之后的投资写入基础。已完成范围包括：

- 投资投影安全与精度；
- 用户范围 Instrument 与 Account / Asset 绑定；
- 单 Asset Legacy opening migration；
- 手工 BUY、SELL 与 DIVIDEND 入账；
- 追加式 standalone reversal；
- replacement 命令封装、规范 replay 基础与 replacement 写路径；
- 原子 Account.balance 变更、交易驱动 Asset 投影、不可变回执与追加式审计；
- 幂等、确定性加锁、锁等待超时 / deadlock 映射、unknown-commit 恢复，以及 PostgreSQL migration / runtime 验证。

本文是对已完成子阶段的管理性汇总，不重新审查或改变其已接受实现。

## 当前投资模块能力

仓库当前提供用户范围 Instrument；唯一 Account / Instrument / Asset 绑定；带认证的 Legacy opening migration；BUY、SELL 与 DIVIDEND 入账；按加权平均成本对完整历史执行 Position replay；Position 关闭与重新打开；原子 Account.balance 变更；交易驱动 Asset 投影；追加式 standalone reversal；replacement correction；不可变原始事实、回执与纠正命令；request hashing 与幂等恢复；确定性加锁；安全的锁等待超时 / deadlock 映射；unknown-commit 恢复；规范 replay anchor；replay trace 与 digest；PostgreSQL 17.10 集成覆盖与 V13 runtime 验证。

## 明确不在 Phase 2B 范围内

以下能力尚未实现，但不阻塞本次关闭：Portfolio 专用 read model / API；面向用户的 InvestmentTransaction 查询、详情或审计时间线 API；投资前端；Position 详情或纠正 UI；历史 Position 快照；历史价格；收益曲线；多币种账务；FIFO / lot 账务；公司行动；券商或交易所集成；AI Agent 能力。

## 已废弃或被取代的方向

- 通用 InvestmentTransaction 写 endpoint 已被实现的按类型 API 取代。
- 更新原始事实或将 `REVERSED` status 作为纠正模型的方向，已被追加式 reversal 与 replacement 取代。
- 早期 `replaces_transaction_id` 方向不再适用。
- 不得仅为重复已关闭子阶段的工作而重新打开 Phase 2B-4 与 Phase 2B-5B。
