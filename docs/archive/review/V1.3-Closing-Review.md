# v1.3 Engineering Polish Closing Review

本文档记录 Personal Finance OS v1.3 Engineering Polish 的正式收尾结论。本阶段只补齐工程化能力，不扩大业务模型。

## 1. 版本目标

v1.3 的目标是：

- 补齐 PostgreSQL 集成测试、CI、接口契约和数据库演进规范；
- 增强 Controller/API、安全链路和用户隔离验证；
- 提升前端共享组件和页面布局的可维护性；
- 保持金融规则以后端为准，不提前引入行情、汇率、AI 或完整投资交易模型。

## 2. 完成范围

### 2.1 PostgreSQL Testcontainers

- 使用 Testcontainers `1.20.0` 和 `postgres:17-alpine`；
- 通过 `@DynamicPropertySource` 注入容器数据源；
- 不使用 H2，不连接固定测试数据库；
- Dashboard Mapper、API integration 和 Flyway migration 均使用真实 PostgreSQL；
- `FlywayMigrationIntegrationTest` 验证空库迁移、`flyway_schema_history` 和 6 张业务表。

### 2.2 GitHub Actions

- Backend 使用 Java 21、Maven Wrapper 和 `./mvnw -B clean test`；
- Frontend 使用 Node 22、`npm ci`、test、lint 和 build；
- Workflow 权限为 `contents: read`；
- 无 GitHub Secrets、无部署流程。

### 2.3 Controller / API 测试

- User、Account、Asset、Category、Transaction、Dashboard 六个 Controller 均有 MockMvc slice contract 测试；
- 测试导入真实 `SecurityConfig`；
- 真实 API integration 使用真实 JWT 和 PostgreSQL Testcontainers；
- 覆盖用户隔离、交易余额联动、分页和组合筛选；
- 覆盖禁用用户旧 token 返回 401。

本阶段不声称 100% 分支覆盖。

### 2.4 OpenAPI / Swagger

- 使用 `springdoc-openapi-starter-webmvc-ui:2.6.0`；
- 六个 tag、24 个 operation summary；
- 注册和登录 2 个接口公开，其余 22 个业务接口声明 JWT 安全要求；
- 提供 OpenAPI JSON 和 Swagger UI；
- `OpenApiIntegrationTest` 验证 OpenAPI JSON、Swagger UI、tag 和安全声明。

### 2.5 Flyway

- 使用 Flyway `10.20.0`、`flyway-core` 和 `flyway-database-postgresql`；
- 当前唯一 migration 为 `V1__baseline.sql`；
- 已删除 `schema.sql`，移除 Spring SQL Init；
- 未启用 `baseline-on-migrate`；
- 已验证 PostgreSQL 17 空库迁移；
- ADR-005 已记录并 Accepted。

### 2.6 前端工程化

- 共享 `PageResult<T>`；
- 新增 `PageHeader` 和受控展示型 `Pagination`；
- 新增并复用 `page-panel`、`data-table` 等页面样式；
- Accounts、Assets、Transactions 已完成共享布局和分页组件迁移；
- API endpoint、payload、分页算法和业务逻辑保持不变；
- 分页业务逻辑、筛选和删除后的页码回退仍保留在页面内；
- Pagination 上一页 / 下一页按钮显式使用 `type="button"`，并有对应回归测试。

## 6. 已知限制

以下限制不阻塞 v1.3 关闭：

- Dashboard 缺少真实 JWT 双用户端到端隔离用例；
- 缺少完整过期 / 篡改 JWT 的 Spring Boot 集成测试；
- 前端共享组件缺少渲染和交互级测试；
- Pagination 当前测试为源码级轻量回归测试；
- 默认运行数据源面向 localhost PostgreSQL；
- 旧 `schema.sql` 数据库需要备份重建或受控 baseline；
- ECharts bundle 大小警告；
- coverage、artifact、分支保护尚未完善；
- `Database.md` 中既有 Known Gaps 继续保留。

## 7. Architecture.md 说明

`Architecture.md` 已冻结。本文件中关于图表库未来选型的旧措辞属于历史文档债务；当前 ECharts 实现已由代码、README 和 v1.2 Closing Review 证明。本轮不修改冻结文件，后续架构级调整继续通过 ADR 记录。

## 8. 明确未纳入 v1.3

- 行情 API；
- 资产历史价格业务接入；
- 汇率；
- 完整投资交易模型；
- `BUY` / `SELL`；
- AI 财务分析；
- 生产级部署体系。
