## 2. 已实现端点与公共契约

以下 bearer-protected GET 端点已经实现：

- `GET /api/v1/investment/portfolio`
- `GET /api/v1/investment/positions`
- `GET /api/v1/investment/positions/{positionId}`

Position 列表支持 `status=OPEN|CLOSED|ALL`、可选 `accountId` / `instrumentId`、opaque cursor 与 1-100 的 size，稳定顺序为 `(instrumentId ASC, accountId ASC, positionId ASC)`。金融值按冻结 scale 输出 JSON string；OpenAPI 明确 bearer security、参数边界、200/400/401/404/500 响应和公共 schema。

## 3. Portfolio、Position 与 Legacy 边界

- Portfolio 仅统计 `TRANSACTION_DRIVEN` Position，不包含 Legacy Asset、Account 现金余额、全部资产或净资产。
- quantity、avgCost、totalCost、realizedProfitLoss、status 与 projectionVersion 来自当前 `Asset` 持仓投影；普通 GET 不逐笔 replay，也不从历史 receipt 重建第二套当前真值。
- Position detail 返回当前 Asset、Account 与 InvestmentInstrument 的展示信息，并保持当前值与历史回执边界。
- Legacy Asset 不进入 Portfolio 或 Position API；closed Position 可按显式 status 查询，默认列表只返回 open Position。
- 所有入口均从认证用户取得 `userId`，SQL 层同时执行 ownership 过滤；不存在与跨用户资源使用相同安全 404。

## 4. 缓存参考估值语义

Reference valuation 是非账务参考信息，只批量读取缓存 quote 与 FX：

- GET 不调用 MarketDataProvider / ExchangeRateProvider；
- GET 不触发 quote / FX refresh，不写数据库，也不获取写锁；
- Portfolio 缓存估值合计排除 manual Asset price，避免把用户录入值伪装成市场缓存值；
- 支持 `FRESH`、`STALE`、`PARTIAL`、`UNAVAILABLE` 与 coverage 计数；估值不可用时 reference 对象仍存在；
- 100 个 Position 的查询使用一次 Position page 查询、一次 quote batch 和一次去重后的 FX batch，不发生逐 Position N+1。

这套估值不会覆盖 Asset 投影、Account.balance 或 investment ledger，因而不形成第二套账务真值。

## 5. 独立复审发现与修复

复审起始实现未发现 P0，但有两类 P1 关闭证据不足：

2. OpenAPI 只声明 200，缺少 400/401/404/500；补充响应后，新测试进一步发现 Portfolio 与 Position 的两个嵌套 DTO 同名为 `ReferenceValuation`，Springdoc 合并 schema 并丢失 Portfolio coverage 字段。

修复内容：

- 增加 PostgreSQL、Service、WebMvc 与 OpenAPI 回归测试，直接覆盖上述证据；
- 为三个公开端点补充错误响应与 path/query 参数边界；
- 将嵌套 schema 分离为 `PortfolioReferenceValuation` 与 `PositionReferenceValuation`，消除 Springdoc 名称碰撞。

修复后没有遗留 P0/P1。

## 6. PostgreSQL 并发、只读与批量证据

`InvestmentReadQueryPostgresIntegrationTest` 最终包含 12 个测试，并在 Testcontainers PostgreSQL 上连续运行两次：

- 使用真实 Spring transactional proxy 与并发 writer，证明 Portfolio 与 Position detail 在 `REPEATABLE READ` 中保持同一快照；

- 对 MarketQuoteService、ReferenceValuationRefreshService、ExchangeRateService 与两个 Provider 做零调用断言；
