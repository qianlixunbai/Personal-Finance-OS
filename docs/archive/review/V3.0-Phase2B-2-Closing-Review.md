## 空 Position 决策

本阶段不创建交易驱动 Position。现有账本语义将 `Asset` 定义为投资事实的投影；没有事实却存在数量为零、状态为 CLOSED 的投影会违反该边界。内部绑定 Service 只为后续原子投资命令校验 Account + Instrument 组合。

## 验证

- PostgreSQL 17 Testcontainers 覆盖 migration、V6 升级 / 快速失败、Mapper 约束和并发 Instrument 创建。
- 并发创建 Instrument 的结果为一次成功和一次 409；唯一键确保只保留一行。
- 只有命名的 Instrument 唯一约束触发 `23505` 时才转换为 409。其他数据库完整性失败会重新抛给现有通用 handler。
