# 开发日志（2026-07-06）：P1 问题修复

## 目标

只修复 Review 中确认的 P1 问题，不处理 P2，不修改数据库结构，不修改已冻结的 Architecture 文档。

## 修复范围

本次修复覆盖以下 P1 问题：

- 账户停用逻辑错误。
- 配置文件存在硬编码数据库账号密码与 JWT secret。
- MyBatis stdout SQL 日志开启。
- 登录未校验用户状态。
- JWT 旧 token 未重新确认用户状态。
- 资产价格更新缺少正数校验。

## 处理过程

1. 调整 `AccountService` 停用账户逻辑：有历史流水时允许停用，禁止删除；无论是否有历史流水，停用均合法。
2. 调整 `application.yml`：数据库账号密码与 JWT secret 改为环境变量占位。
3. 关闭 MyBatis stdout SQL 日志。
4. 调整 `UserService`：登录时必须校验用户 `status`。
5. 调整 `JwtAuthFilter`：token 校验后重新确认用户状态，禁用用户旧 token 不得继续访问。
6. 调整 `AssetController` 与 `AssetService`：`updatePrice` 必须校验 `price > 0`。
7. 为关键修复补充单元测试。

## 影响范围

- 账户模块：停用行为更符合业务规则，不再因存在历史流水而阻止停用。
- 用户模块：禁用用户无法登录。
- 认证模块：禁用用户即使持有旧 token，也无法继续访问受保护资源。
- 资产模块：资产价格更新增加正数校验。
- 配置管理：敏感信息不再硬编码到配置文件中。

## 风险

- 部署环境必须提供数据库账号、数据库密码与 JWT secret 等环境变量。
- 已禁用用户的旧 token 会立即失效，属于预期的安全行为。
- 测试覆盖集中在 P1 修复点，未扩展处理 P2 问题。
