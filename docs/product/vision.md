# 产品愿景

Personal Finance OS 帮助个人用户维护自己的财务事实，并以可验证、可追溯的方式理解账户、现金流、资产和投资持仓。

系统的核心不是替用户执行资金或证券操作，而是可靠地回答：

- 我记录了哪些财务事实；
- 这些事实如何影响账户余额和持仓；
- 当前结果能否从历史事实重新计算；
- 错误数据如何在不篡改历史的前提下纠正；
- 批量录入、重试和并发情况下是否仍然只产生一次正确影响。

## 产品原则

### 服务端权威

金额计算、账户余额、投资重放、Dashboard 聚合、Import Preview 和 Receipt 由后端负责。前端提供交互与展示，不建立第二套金融真值。

### 事实与投影分离

普通流水表达可维护的日常财务记录；投资账本表达 append-only 事实；`Account.balance` 与 transaction-driven `Asset` 是受控投影。历史回执不冒充当前真值。

### 可审计纠正

投资错误通过 reversal 或 replacement 追加纠正，而不是覆盖原始事实。批量导入通过冻结 Preview、幂等 Confirm 和权威 Receipt 保留可追踪的处理结果。

### 简单且可演进

系统保持前后端分离的模块化单体，不为尚未冻结的能力提前引入微服务、Redis、MQ 或复杂 DDD。架构级变化通过 ADR 决策。

### 用户控制

手工录入和受控文件导入是正式数据入口。外部行情仅提供参考值；银行或券商自动同步、真实交易执行和 AI 写入都不是当前产品能力。

## 主要使用方式

当前以 Web 为主要客户端。用户可以维护基础财务、查看 Dashboard 和投资视图、执行受控投资命令及纠正，并通过 CSV / XLSX 工作流导入普通流水。
